# PayFlux

PayFlux is an agentic merchant-support investigation system built using completely synthetic fintech data.

The system will:

- Understand merchant-support tickets
- Investigate synthetic payments, settlements and refunds
- Retrieve relevant support policies
- Recommend evidence-backed resolutions
- Request human approval before sensitive actions
- Record agent actions for evaluation and debugging

## Technology Stack

- Python
- FastAPI
- React
- TypeScript
- SQLite
- OpenAI Agents SDK
